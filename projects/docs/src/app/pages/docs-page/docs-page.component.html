Getting started

ngx-iconify-stack is a Signal-based Angular wrapper for Iconify. It combines an offline, SSR-safe icon subset with a CDN fallback: icons you reference statically render as inline SVG on the server, while everything else resolves from the Iconify CDN at runtime.

Install

{{ installCommand }}

The schematic asks which delivery mode you want:

  • autohost (default) — generates the offline icon subset, adds the required @iconify-json/* dependencies (installing missing sets automatically), and wires the prebuild script.

  • cdn — CDN only: no subset file and no prebuild wiring, you just call provideIconify().

If you use the CDN fallback, also install the peer dependency iconify-icon — the web component that renders CDN icons.

inline, forceCdn and noObserver use a booleanAttribute transform, so presence syntax works: <ngx-iconify icon="mdi:home" inline /> is equivalent to [inline]="true".

All inputs are signals, so dynamic changes recalculate reactively — the component works in zoneless apps. Every input mirrors an <iconify-icon> attribute; see the Iconify attribute docs.

Rendering modes

How an icon renders depends on whether it lives in the offline subset:

  • In the subset — rendered as an inline <svg> on the server. No @defer needed and no hydration gap.

  • Not in the subset — rendered through the <iconify-icon> web component, resolving from the Iconify CDN at runtime.

  • [forceCdn]="true" — skips the subset lookup and always renders <iconify-icon> from the CDN, even when the icon exists in the subset (useful for icons deliberately kept out of the generated subset). The scanner also EXCLUDES any icon referenced with forceCdn, so regenerating drops it from icon-subset.ts.

Offline subset & schematics

The subset scanner captures only template literals — <ngx-iconify icon="mdi:home" /> or icon = 'mdi:home'. Icons resolved at runtime from signals or services are not captured (and are not false positives): they resolve via the Iconify CDN by default without breaking.

  • To include a dynamic icon in the SSR subset, add it to dynamicSubsetIcons in src/ngx-iconify/icon-manifest.ts, or run add-icon to append it and regenerate.

  • Regenerate the subset after template changes. Missing @iconify-json/* sets are declared and installed automatically on the next run.
