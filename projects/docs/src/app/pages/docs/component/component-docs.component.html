inline, forceCdn and noObserver use a booleanAttribute transform, so presence syntax works: <ngx-iconify icon="mdi:home" inline /> is equivalent to [inline]="true".

All inputs are signals, so dynamic changes recalculate reactively — the component works in zoneless apps. Every input mirrors an <iconify-icon> attribute; see the Iconify attribute docs.
