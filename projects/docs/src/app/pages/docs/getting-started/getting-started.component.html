Getting started

ngx-iconify-stack is a Signal-based Angular wrapper for Iconify. It combines an offline, SSR-safe icon subset with a CDN fallback: icons you reference statically render as inline SVG on the server, while everything else resolves from the Iconify CDN at runtime.

Install

{{ installCommand }}

The schematic asks which delivery mode you want:

  • autohost (default) — generates the offline icon subset, adds the required @iconify-json/* dependencies (installing missing sets automatically), and wires the prebuild script.

  • cdn — CDN only: no subset file and no prebuild wiring, you just call provideIconify().

If you use the CDN fallback, also install the peer dependency iconify-icon — the web component that renders CDN icons.
